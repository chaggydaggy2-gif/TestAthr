## 🚀 كيف تبدأ؟

### 1️⃣ تشغيل المنصة محلياً:
```bash
npm run dev
```
المنصة ستعمل على: http://localhost:3000

### 2️⃣ إنشاء حسابات المعلمات:
1. افتح [Supabase Dashboard](https://supabase.com/dashboard)
2. اذهب إلى SQL Editor
3. انسخ محتوى [CREATE-TEACHERS-EASY.sql](CREATE-TEACHERS-EASY.sql)
4. شغّل الكود (اضغط RUN)
5. تحقق من النجاح!

### 3️⃣ توزيع بيانات الدخول:
- اطبع [بطاقات-دخول-المعلمات.txt](بطاقات-دخول-المعلمات.txt)
- وزع على المعلمات
